# Stella

https://github.com/user-attachments/assets/15f8981d-3a6d-4248-a0aa-d359e83483a3

A personal AI assistant you talk to in one chat, working on your computers, in the cloud and on your phone.

[Download and get started](https://stella.sh).

## Features

- **Computer and browser use.** Works with your apps, files and browser.
- **Your devices or the cloud.** Run work on any of your connected computers or in the cloud.
- **It can change itself.** Ask and Stella rewrites its own app. No plugins, no limits on what you can change.
- **One chat.** Keep talking in the same conversation across your devices.
- **Scheduling.** Set reminders, recurring tasks and checks that run for you.
- **Connectors.** Connect your services or add any MCP server.
- **Mobile.** iOS and Android apps, with self-hosted server support too; see the guide below for required app versions.
- **Your engine and models.** Runs on Stella's own runtime (pi) or Claude Code, with ChatGPT sign-in, provider API keys and local models also supported.
- **Open source.** MIT licensed.

## Self-hosting

Run your own Stella server on your own Cloudflare account.
Your conversations, files, memory and settings stay there.

The simplest way: give your AI agent this link and ask it to do the setup:

**https://stella.sh/self-host.md**

You need a Cloudflare account on Workers Paid ($5/month plus usage) and your own Claude or ChatGPT subscription for models.
The guide covers setup, connecting your apps, required app versions and updates.
For the manual reference, see [SELF_HOSTING.md](SELF_HOSTING.md).
