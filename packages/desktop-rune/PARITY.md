# Parity checklist: Rune Stella vs Electron Stella

Every line is proven in the running Rune app (screenshot or recording on the private display,
real-display numbers for performance) before it is ticked. Source of truth is master's
`packages/desktop-ui/src` and `packages/desktop/electron`.

## Platform (engine + host)
- [ ] Windows: main shell, detached viewer windows (tear-off), companion, overlay, Show Stella panel, dialogs' parent
  - macOS: the main shell, a torn-off viewer window docking back (~/.stella/outputs/stella-rune/shell/clips/viewer-detach.mp4, ~/.stella/outputs/stella-rune/shell/sbs/detached-dark.jpg), the companion's mark and panel windows (~/.stella/outputs/stella-rune/shell/sbs/companion-expanded-*.jpg) and the full-screen overlay (~/.stella/outputs/stella-rune/shell/sbs/overlay-region-hint.jpg) open as their own windows, matching Electron's bounds (mark 1572,953; panel 1300,541 400×560). Show Stella panel and dialogs' parent are not proven here; Windows and Linux are not run.
  - Linux (omarchy, Hyprland, XWayland at scale 1.6): the main shell opens floating with the same app_id as Electron (stella-v2). The background media window ("Stella media") opens override-redirect, so it takes no focus and is not listed by window managers or taskbars. It is also absent from the accessibility tree, as Electron's hidden window is (~/.stella/outputs/stella-rune/engine/background-window-linux.txt). A second monitor is not tested (no hardware).

Speech and Substitutions follow Chromium's view (engine `text_services.rs`): Show Substitutions and Start Speaking are always enabled, Stop Speaking only while speaking, and Smart Quotes, Smart Dashes and Text Replacement only while an editable field takes them, each checked from the `WebAutomatic…Enabled` defaults; Start Speaking speaks the focused field's selection, else the window's. Cross-checked only; the macOS AX read of the bar is pending (steps in memory). Typing applies them as Chromium's view does (Rune 4878c4df): after a key press inserts text, `NSSpellChecker` checks the field around the caret for the types turned on; a smart quote or dash reaching the caret replaces at once, a text replacement shows AppKit's correction bubble that the next edit or a click accepts, and a `spellcheck={false}` field takes replacements only. Cross-checked for aarch64-apple-darwin only; the Mac proof is pending (steps in memory).
